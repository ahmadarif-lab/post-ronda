## What's new in 0.3.4

### One timeout for the whole app

- **The request timeout can now be set once for the whole app**, in *App settings → Network* (default and maximum: 1 hour). A request uses its own timeout if it has one, otherwise the project's default, otherwise the app-wide value.
- **Requests saved with the old 30 s default now follow the setting** instead of staying at 30 s, so long-running calls no longer time out unless you want them to.
- Imports and generated code (curl and others) use the timeout that actually applies to the request.

### Clearer errors

- **A failed send now shows "Request failed" in the response pane** with the full error message. If the request timed out, it also suggests raising the timeout.

### Settings

- Project settings and app settings are now **one window with Project / App tabs** at the bottom left. Switching tabs keeps the window size and no longer fades.
- The per-request settings tab is gone. The gear icon and Cmd/Ctrl+, open the project settings.
- Section headings in settings are stronger than field labels, and the timeout is also shown in words (for example "1 hour").

### Install or update

In the app, open *Software updates* in the settings, press **Check now**, then **Update now**. Or download the package for your system below. Release builds are not code-signed yet, see the README for the first-launch warning on macOS and Windows.
