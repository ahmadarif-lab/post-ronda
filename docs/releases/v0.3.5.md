## What's new in 0.3.5

### macOS on Intel

- **Post Ronda now has a native build for Intel Macs**: `Post-Ronda-macos-x86_64.pkg` (installer) and `Post-Ronda-macos-x86_64.zip` (archive). Before, only Apple Silicon (`arm64`) packages were published.
- **Software updates pick the right file for your Mac** automatically, so Intel users can update from inside the app.

### Install or update

In the app, open *Software updates* in the settings, press **Check now**, then **Update now**. Or download the package for your system below. Release builds are not code-signed yet, see the README for the first-launch warning on macOS and Windows.
