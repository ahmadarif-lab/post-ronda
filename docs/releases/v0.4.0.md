## What's new in 0.4.0

### Git sync and logins per project

- **Automatic push**: turn on *Commit and push after every save* in *Project settings → Git*. A few seconds after the last save the collection is committed and pushed. If a teammate pushed first, their changes are merged in; when you both edited the same part, nothing is lost and you are told.
- **Automatic pull**: *Pull when the project opens and every N minutes* keeps a collection shared through Git current. It only runs while you have no unsaved requests, and your edits made during a pull are kept.
- **A login of its own for each project**: use the Git on your computer, or type a username and access token, or pick an SSH key file, so a project can use a different account than your terminal. *Test connection* checks it. Credentials are stored outside the project folder, readable by you alone, and never put on a command line. An optional commit author (name and email) is available too.
- **Git feedback in the status bar**: a small spinner and a short message replace the toasts and the greyed-out window while Git works, and the buttons no longer disappear.

### Fixes

- After a pull, the next autosave could write the old copy back over what was just pulled. The app now takes the pulled files as the saved state.
- *Pull* now rebases your unpushed commits onto the remote instead of refusing, and untracked files no longer block it.
- The login choices in the Git settings no longer shift when you hover them, and the fields there are as tall as the ones in the other settings.

### Install or update

In the app, open *Software updates* in the settings, press **Check now**, then **Update now**. Or download the package for your system below. Release builds are not code-signed yet, see the README for the first-launch warning on macOS and Windows.
